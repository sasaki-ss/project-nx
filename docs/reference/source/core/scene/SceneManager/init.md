# nx::core::scene::SceneManager::init

## シグネチャ
```cpp
bool init();
```

## 概要
シーン管理を初期化します。
`set_initial_scene` で初期シーンを指定していれば、そのシーンを生成して `init` を呼び、積みます。
指定していなければ、シーンを積まずに初期化を終えます (仮起動)。

## 戻り値
初期シーンを指定していない場合と、初期シーンの生成と `init` に成功した場合は `true`。
初期シーンの生成関数が登録されていない場合と、初期シーンの `init` が `false` を返した場合は `false`。
