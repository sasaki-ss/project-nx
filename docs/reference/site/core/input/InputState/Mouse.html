core/input
enum class

nx::core::input::Mouse

enum class Mouse {
    Left,
    Right,
    Middle,
    Extra1,
    Extra2,
    Count
};

概要

マウスボタン識別子を表す列挙型です。

値

値説明
Left左ボタン
Right右ボタン
Middle中央ボタン
Extra1拡張ボタン1
Extra2拡張ボタン2
Count要素数管理用

備考

具体的なボタン番号は Adapter 側でマッピングします。

関連項目

  • MouseHash
  • MousePoint

サンプルコード

#include <core/input/InputState.h>
using nx::core::input::Mouse;
int main() {
    // Mouse の値を選択して状態を扱う
    auto state = Mouse::Pressed;
    (void)state;
    return 0;
}
