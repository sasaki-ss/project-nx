core/input/InputState
enum class

nx::core::input::InputState

enum class InputState {
    Pressed,
    Down,
    Released
};

概要

入力の遷移状態を表す列挙型です。

値

値説明
Pressedこのフレームで押された
Down押下中
Releasedこのフレームで離された

備考

状態判定ロジックは InputSystem 側に依存します。

関連項目

  • InputSystem
  • InputState

サンプルコード

#include <core/input/InputState.h>
using nx::core::input::InputState;
int main() {
    // InputState の値を選択して状態を扱う
    auto state = InputState::Pressed;
    (void)state;
    return 0;
}
